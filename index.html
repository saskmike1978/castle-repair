Wait Time Castle Repair Tool

Use a computer with Chrome or Edge. Do not use a phone or tablet.

This tool needs Chrome or Edge on a computer. Please open this page in one of those.

Step 0: Install the driver (one time)

Your castle uses a CH340 chip. Install its driver before you connect the castle, then restart the computer.

  • Windows: download the CH340 driver
  • Mac: download the CH340 driver. After installing, open System Settings → Privacy & Security and click Allow if the driver is blocked. Then restart.

Step 1: Connect the castle

Plug the castle into this computer with a USB cable, then press the button below.

Chrome or Edge will show a list of connections. Choose the one that mentions USB-SERIAL CH340 or CH340, usually with a COM number such as COM4. The number may be different on your computer, so pick the CH340 entry, not the number.

Step 2: Check the castle

Click the button below. The page listens for 10 seconds and shows any messages the castle sends.

You may need to repeat this step up to 4 times to catch any messages the castle sends. Keep the castle connected the whole time.

Step 3: Install the castle software

Only do this if we asked you to, or if the check showed no messages. Do not unplug the castle during this step.

Step 4: Set the castle's Wi-Fi

Use this if the castle cannot join your Wi-Fi. Type your Wi-Fi name and password exactly as they are on your router (capital letters count). Keep the castle connected while sending. This needs the newest castle software from Step 3.

Last resort: Erase everything

Use this only if we asked you to. It deletes all saved settings, Wi-Fi details, and ride names from the castle. After it finishes, you must do Step 3 again to install the castle software.
